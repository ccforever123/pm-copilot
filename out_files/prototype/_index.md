# Prototype Delivery Index

> `out_files/prototype/` is the single output location for generated prototype files in V1.7.

## Directory Role

- Store generated HTML prototype versions.
- Store prototype review results when they are part of the delivery.
- Keep each prototype version in its own folder, for example `out_files/prototype/v1/`.

## Generation Rules

- Do not generate new prototype files under root `prototype/`.
- Root `prototype/` is legacy reference only.
- When a prototype is created or revised, update this index before handing off.
