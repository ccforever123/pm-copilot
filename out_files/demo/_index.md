# Demo Delivery Index

> `out_files/demo/` is the single output location for generated runnable demos in V1.7.

## Directory Role

- Store runnable demo versions.
- Store demo validation notes when they are part of the delivery.
- Keep each demo version in its own folder, for example `out_files/demo/v1/`.

## Generation Rules

- Do not generate new demo files under root `demo/`.
- Root `demo/` is legacy reference only.
- When a demo is created, tested, or revised, update this index before handing off.
