# Sub-Agent 分发规范

> 本文件由阶段三并行生成原型时调用。为每个页面启动 Sub-Agent 时，必须包含以下四要素，缺一不可。

---

## 四要素模板

```
【任务标题】生成 {页面名}.html

【执行范围】
仅生成并保存 {prototype_folder}/{页面名}.html，不修改其他任何文件。

【验收标准】
- 使用真实 UI 组件结构（表单、按钮、表格、弹窗等），不得用纯文字描述替代
- 包含所有相关交互状态：空状态、填充态、错误态、加载态
- 与其他页面的导航链接可点击（目标页面尚未生成时使用占位路径，如 ./order_list.html）
- 按原型备注模板结构，在 HTML 文件中嵌入交互逻辑说明

【上下文】
需求文档相关章节：
{章节内容}

原型备注模板结构：
{备注模板内容}

本次需生成的完整页面列表（用于导航链接）：
{已确认页面列表}
```

---

## 并行前提（全部满足才可并行）

- 各页面内容相互独立，不存在内容依赖
- 每个 Sub-Agent 只写入自己负责的一个文件
- 每个 Sub-Agent 的生成范围清晰，无歧义

---

## 失败处理

- 生成成功 → 文件名写入 `prototype_pages.completed`
- 生成失败 → 文件名写入 `prototype_pages.failed`，记录失败原因
- 失败项重新启动 Sub-Agent 重试，最多 3 次
- 超过 3 次仍失败 → 上报用户，说明具体问题，由用户决策
